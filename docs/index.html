What this project is

1 — A business we invented

We generated {{ weeks }} weeks of ad spend across {{ nChannels }} channels and the sales they produced, using rules we chose. Because we wrote the rules, we know the true effect of every channel. Real advertisers never have that.

2 — A model that only sees the data

The model is given spend and sales, nothing else, and asked to work out what each channel did. It reports every answer as a range, because a model that pretends to be certain is more dangerous than one that admits doubt.

3 — Checked, then put to work

We compare the model’s answers with the truth we hid from it. Then we use the model the way a marketing team would: to decide where next week’s budget should go.

Objective: steady-state media sales Σc βc · hill(xc) evaluated on every posterior draw, scored by the posterior mean or by P10 of the total within each draw (never a sum of per-channel quantiles). Constraint Σ xc = budget, 0 ≤ xc ≤ max observed weekly spend. SLSQP from {{ optStarts }} starting allocations, Nelder-Mead polish for the non-smooth quantile objective. Lift is computed within draws against the current allocation, so its range respects the shared uncertainty. Code: mmm_sandbox/optimizer.py.

How this was built

The Bayesian model is fit once, offline, with PyMC-Marketing and NUTS, then served from a saved posterior. Nothing on this page re-samples, so every interaction is instant — the same train/serve split production ML systems rely on. Every number shown here is exported from that posterior by a script, not typed in.
